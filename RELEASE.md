# MAGOH Spell 1.0

MAGOH Spell porta in QGIS il modello dati archeologico MAGOH. La versione 1.0 permette di creare un progetto locale, consultare le relazioni tra schede, importare dati MAGOH tramite API ed esportare schede PDF o un progetto basato sul Template GNA 1.6.0.

Le schede create nel progetto ricevono un codice leggibile distinto per intervento, ritrovamento ed evidenza. La ricerca per attributi e i filtri per cronologia e categoria aiutano a selezionare i record. Durante la conversione in GNA, un registro documenta il collegamento tra i dati di origine e le schede prodotte.

**Installazione** — Scarica l’allegato `MAGOH_Spell_V1.0.zip` e selezionalo in QGIS da **Plugin → Gestisci e installa plugin → Installa da ZIP**.
